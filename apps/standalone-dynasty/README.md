> 古文化渊源 · 智能新范式 — AI Family + Dynasty 双架构 Agent 体系

## 启动

```bash
pnpm --filter @yyc3/app-standalone-dynasty dev
```

## 效果

```
欢迎弹窗 → 王朝首页 + Hub浮窗 (金色 #C9A96E)
浮窗: 对话 / 王朝命令 / 提示词 / 配置

主页面:
├── 朝堂大厅 — 三省六部 12 Agent 看板

```
