## 一、记录规则

1. **一变更一条目**：条目 ID 形如 `A-YYYYMMDD-NN`，只追加、不删改；撤销用「回滚」条目记录。
2. **必填四要素**：改了什么（What）、为什么（Why）、怎么验（Verify）、结果（Result）。
3. **结果只写实测**：必须能在本地或 CI 复现；未验证写「未验证」，不得写「应该」。
4. **状态枚举**：`✅ 已验证` / `🔄 进行中` / `⬜ 待验证` / `⛔ 回滚`。
5. **联动更新**：改变现状判断的条目，需同步修订 [002-项目审计报告](./002-项目审计报告-首次技术调研全维度.md) 对应章节。
