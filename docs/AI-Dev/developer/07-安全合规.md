## 二、数据安全

### 2.1 localStorage 安全

#### 命名空间隔离

```typescript
// ✅ 正确：每个插件使用独立命名空间
const storage = createSystemStorage("target");
storage.set("lastResult", data);
// 实际 Key: yyc3:target:lastResult

// ❌ 禁止：直接操作 localStorage
localStorage.setItem("myKey", data);  // 无命名空间，易冲突
```

#### 禁止存储的数据

| 数据类型 | 禁止原因 |
|----------|----------|
| API 密钥 | 前端存储可被提取 |
| 用户密码 | 明文/哈希均不可 |
| 敏感个人信息 | 身份证/银行卡/手机号 |
| 认证 Token | 使用 HttpOnly Cookie |

### 2.2 数据传输安全

```typescript
// ✅ HTTPS 强制
const API_BASE = "https://api.yyc3.example";

// ✅ 敏感字段脱敏
function maskPhone(phone: string): string {
  return phone.replace(/(\d{3})\d{4}(\d{4})/, "$1****$2");
}
```

## 三、API 密钥管理

### 3.1 分层原则

| 场景 | 存储位置 | 说明 |
|------|----------|------|
| 服务端密钥 | 环境变量 / Vercel Secrets | 绝不进入前端 bundle |
| 用户自备 Key | 浏览器内存 | 可选，不持久化 |
| LLM 网关 Key | 服务端 `SERVER_MASTER_KEY` | AES-256-GCM 加密 |

### 3.2 前端禁止

```typescript
// ❌ 禁止：硬编码密钥
const OPENAI_API_KEY = "sk-xxx";

// ❌ 禁止：写入 localStorage
localStorage.setItem("apiKey", "sk-xxx");

// ✅ 正确：仅保留内存会话级
let sessionKey: string | null = null;
```

### 3.3 服务端加密（plugin-llm）

项目 `plugin-llm` 提供 AES-256-GCM 加密，用于服务端密钥保护：

```typescript
import { encrypt, decrypt } from "@yyc3/plugin-llm";
// 主密钥来自环境变量 SERVER_MASTER_KEY（32字节 base64）
```

## 五、XSS 防护

### 5.1 React 默认转义

React 默认转义输出内容，禁止绕过：

```tsx
// ✅ 正确：自动转义
<div>{userInput}</div>

// ❌ 禁止：危险注入
<div dangerouslySetInnerHTML={{ __html: userInput }} />
```

### 5.2 链接校验

```typescript
// ✅ 正确：白名单校验 URL
const SAFE_SCHEMES = ["https:", "http:", "mailto:"];
function sanitizeUrl(url: string): string {
  const u = new URL(url, window.location.origin);
  return SAFE_SCHEMES.includes(u.protocol) ? url : "";
}
```

## 六、权限控制

### 6.1 插件隔离

| 边界 | 策略 |
|------|------|
| 插件间组件 | 禁止直接 import，走 EventBus |
| 插件间存储 | 禁止直接读写，走命名空间工厂 |
| 路由结构 | 禁止互相依赖 |
| Shell 核心 | 禁止修改接口定义 |

### 6.2 错误信息脱敏

```typescript
// ✅ 正确：面向用户只显示友好信息
catch (e) {
  logger.error(e);            // 内部记录详情
  return { error: "服务暂不可用" };  // 用户只见概要
}
```
