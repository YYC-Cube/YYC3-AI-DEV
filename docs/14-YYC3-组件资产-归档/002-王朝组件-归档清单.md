# 王朝治理组件归档

> **_YYC³_**（YanYuCloudCube™ · 注册商标）

**源码根**：`packages/plugin-dynasty/`　**注册入口**：`src/register.ts`（6 路由 / 6 菜单 / 4 Hub 命令）

---

## 一、页面（5）

| 页面 | 文件 | 行数 | 交互 | 状态 | 说明与缺口 |
| ------ | ------ | ------ | ------ | ------ | ---------- |
| 朝堂大厅 | `src/pages/CourtHall.tsx` | 105 | 无 | 可用 | 12 朝臣按「决策/承启/三省/六部/辅助」分层；无筛选与详情抽屉 |
| 旨意板 | `src/pages/EdictBoard.tsx` | 164 | 3 处状态 | 可用 | 六阶段流转看板；任务存 localStorage；无审批人指派 |
| 十三王朝 | `src/pages/DynastyTimeline.tsx` | 148 | 4 处状态 | 可用 | 时间轴 + 朝代详情；数据为静态常量 |
| 勋章墙 | `src/pages/HonorWall.tsx` | 59 | 无 | 骨架 | 静态展示；缺获得条件、进度与授予记录 |
| 中华 Skills | `src/pages/DynastySkills.tsx` | 68 | 2 处状态 | 可用 | 按朝代/分类筛选；缺技能执行入口 |

## 三、引擎与数据

| 模块 | 文件 | 职责 | 状态 | 风险 |
| ------ | ------ | ------ | ------ | ------ |
| 朝臣目录 | `src/agents.ts` | 12 位朝臣 + 4 条 Hub 命令 | 可用 | Hub 命令已接 hash 跳转 |
| 旨意协议 | `src/edict-protocol.ts` | 六阶段状态机 | 完整 | 有单测（`__tests__/edict-protocol.test.ts`） |
| 工作流 | `src/workflow.ts` | 下旨 → 草拟 → 审议 → 派发 → 回奏 → 赏赐 | 可用 | 构造器内订阅 EventBus；含 `Math.random()`，不可确定性重放 |
| 持久化 | `src/persistence.ts` | `yyc3:dynasty:tasks` 本地任务 | 可用 | 硬编码 key 未走 `createSystemStorage`；`catch {}` 静默 |
| 勋章 | `src/honors.ts` | 勋章定义与查询 | 可用 | 无授予流程 |
| 技能 | `src/skills.ts` | 中华 Skills 词条 | 可用 | 无执行器 |
| 朝代 | `src/dynasties.ts` | 十三王朝数据 | 可用 | 静态常量 |

## 五、后续动作

1. `persistence.ts` 改走 `createSystemStorage("dynasty")`，统一命名空间。
2. 旨意板补「指派/回奏/赏赐」交互，去掉随机封驳，改为可配置策略。
3. 勋章墙补获得条件与进度环，复用 `/design` 的 `Progress`/`Badge`。
4. 页面统一迁到 `@yyc3/ui` 基础件，逐步替换手写卡片。
